HTML (siglas en inglés de HyperText Markup Language, traducido como Lenguaje de Marcado de Hipertexto) es el código o componente base estructural que se utiliza para crear y organizar el contenido de una página web

CSS (siglas en inglés de Cascading Style Sheets, traducido como Hojas de Estilo en Cascada) es el lenguaje que se utiliza para diseñar, estructurar visualmente y dar formato al contenido de una página web

JS (siglas de JavaScript)JavaScript es un lenguaje de programación que se utiliza para crear contenido dinámico e interactivo en las páginas web
